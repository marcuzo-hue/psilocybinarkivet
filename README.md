# Psilocybinarkivet

En sökbar svensk sammanställning av forskningen om psilocybin och psilocybinsvamp, med studier, terapi, risker, jämförelser och pågående prövningar.

**Öppna appen:** https://marcuzo-hue.github.io/psilocybinarkivet/

Appen uppdateras varje vecka. Innehållet är en sammanfattning av publicerad forskning och är inte medicinsk rådgivning.
